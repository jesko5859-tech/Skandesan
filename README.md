# 📚 Study Coach - Smart Learning Platform

A modern, animated web application designed to help students master their subjects through intelligent study schedules, interactive quizzes, and organized note-taking. With beautiful geometric animations and intuitive UI/UX, studying has never been more engaging!

## ✨ Features

### 🔐 Secure Authentication
- Beautiful login and signup forms with animated geometric shapes
- Email/password authentication
- Social login options (Google, GitHub)
- Secure password toggle visibility
- "Remember me" functionality
- Session management with localStorage
- Input validation

### 📅 Interactive Schedule Carousel
- **Animated slide carousel** showing daily practice schedule
- Touch-friendly navigation buttons (Previous/Next)
- Dot indicators for quick slide navigation
- Beautiful gradient backgrounds with geometric decorations
- Subject-specific color coding
- Time, topic, and duration displays
- Auto-advance capability
- Smooth transitions between slides

### 📝 Quick Study Notes
- Create notes with title, content, and category
- Organized by subject (Math, English, Science, History)
- Beautiful card-based interface with color-coded borders
- Edit and delete functionality
- Date tracking
- Tag support
- Minimal yet functional design

### ❓ Interactive Quizzes
- Multiple choice questions
- Progress bar with visual question tracking
- Different difficulty levels (Beginner, Intermediate, Advanced)
- Score history and statistics
- Quiz navigation (Previous/Next)
- Real-time score display
- Subject-specific quizzes

### 📊 Progress Dashboard
- Daily goals tracking with progress bars
- Study hours counter
- Quiz completion statistics
- Notes created counter
- Subject-wise performance metrics
- Animated stat cards
- Visual learning analytics

### 🎨 Beautiful UI/UX
- **Animated Geometric Shapes**: Circles, squares, triangles, and pentagons with floating animations
- **Smooth Transitions**: All page changes have fade-in animations
- **Gradient Designs**: Modern linear gradients throughout
- **Hover Effects**: Interactive elements respond with smooth transformations
- **Color-Coded System**: Different colors for different subjects
- **Minimal Design**: Clean, uncluttered interface
- **Responsive Layout**: Works perfectly on mobile, tablet, and desktop

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Styling**: Custom CSS with Grid and Flexbox
- **Storage**: Browser LocalStorage
- **Animations**: CSS keyframes and transitions
- **Design**: Geometric patterns, gradients, and modern UI principles

## 🎯 Key Features in Detail

### Carousel Slider
The schedule section features an **animated carousel** that:
- Displays one study session at a time
- Allows navigation using Previous/Next buttons
- Shows dot indicators for all slides
- Supports click-to-navigate
- Features geometric background decorations
- Uses smooth animations for transitions

### Geometric Animations
The login page includes:
- **Floating Circle** (Orange/Yellow gradient)
- **Rotating Square** (Blue gradient, 45° rotated)
- **Green Triangle** (Animated bounce)
- **Red Pentagon** (Clip-path animation)
- All shapes move smoothly with staggered animations
