# Skandesan - Snake Game

A classic snake game built with HTML, CSS, and JavaScript. Play in your browser and try to get the highest score!

## Features

- Classic snake gameplay
- Smooth controls with arrow keys
- Score tracking
- Game over detection
- Responsive design
- Progressive difficulty

## How to Play

1. Open `index.html` in your web browser
2. Use arrow keys (↑ ↓ ← →) to control the snake
3. Eat the red food to grow longer and earn points
4. Avoid hitting the walls and yourself
5. Try to achieve the highest score!

## Controls

- **Arrow Keys**: Move the snake up, down, left, or right
- **Spacebar**: Pause/Resume the game

## Installation

No installation required! Simply download or clone the repository and open `index.html` in any modern web browser.

```bash
git clone https://github.com/jesko5859-tech/Skandesan.git
cd Skandesan
# Open index.html in your browser
```

## Game Rules

- The snake moves continuously in the direction you command
- Each food eaten increases your score by 10 points
- The snake grows by one segment for each food eaten
- Game ends if the snake hits a wall or itself
- Difficulty increases as your score gets higher
